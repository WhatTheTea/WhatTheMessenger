# ✉️ WhatTheMessenger - Real-time .NET + Angular messenger

This is a simple messaging app created in order to get experience on frontend tech, backend scalability and database nuances.

## Stack:
- .NET 10 w/ ASP.NET Core
- Angular
- SignalR
- PostgreSQL
- Redis
- Docker

## Build

> ⚠️ When building from VS Code with C# Dev Kit, select .NET launch configuration as "dev (single-process)" before launching
using "full-stack (local)" configurations
